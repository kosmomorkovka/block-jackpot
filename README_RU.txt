BLOCK JACKPOT — проект мода для Minecraft Java 26.2 (Fabric)

ВАЖНО: это ИСХОДНЫЙ ПРОЕКТ, а не готовый .jar. В этой среде нельзя проверить сборку против официальных зависимостей, поэтому не буду обещать, что он уже соберётся без исправлений. Версии Minecraft 26.2 используют Java 25 и Fabric/Loom из актуальной ветки.

Что задумано в прототипе:
- баланс монет на игрока;
- /bj — меню-подсказка;
- /bj shop — каталог магазина;
- /bj buy iron|diamond|apple|titan — покупки;
- /bj sell — продажа одного из ресурсов;
- /bj roulette <ставка> — рулетка с открытыми шансами;
- /bj bonus — +250 монет с задержкой;
- клавиша B отправляет команду /bj.

ОГРАНИЧЕНИЯ ЭТОГО ПРОТОТИПА:
- баланс хранится в памяти сервера и сбрасывается после перезапуска;
- интерфейс пока текстовый, не графическое окно; клавиша B открывает подсказки;
- команда продажи ищет первый доступный тип ресурса, продаёт 1 штуку;
- код и версия зависимостей не проверялись реальным запуском/сборкой в Minecraft.
Это стартовый исходник, не финальный игровой мод.

КАК СОБИРАТЬ (нужен интернет):
1. Установи Java 25 (JDK) и IntelliJ IDEA Community.
2. Распакуй ZIP.
3. Открой папку проекта в IntelliJ IDEA как Gradle project.
4. В gradle.properties замени fabric_api_version=0.???.??+26.2 на точную версию Fabric API для Minecraft 26.2 со страницы https://www.fabricmc.net/develop/
5. Дождись импорта Gradle.
6. Запусти Gradle task: build.
7. Готовый JAR появится в build/libs.

Для Essential/LAN:
- мод должен быть установлен у всех игроков, если он включает клиентские функции;
- экономика/команды должны работать на хосте, так как код выполняется на серверной стороне;
- сначала протестируйте в копии мира.
